# 关于 HomeworkChecker 授权模式变更的说明
时间：2026年9月13日  
编辑者：XFTY

**自2026年9月13日的[78f9093](https://github.com/XFTY/HomeworkChecker/commit/78f9093ef989ba86458206746606f6a52dcdcb91)commit**起（不含该commit），HomeworkChecker开源软件授权模式将由原来的 **GNU GPL Version 3**协议 **变更为 Apache License 2.0**。

这意味着：自本次commit发布后，您可以更加自由的使用这个软件的源代码和二进制文件（发行版），但需要注意 Apache License 2.0 的规范。
