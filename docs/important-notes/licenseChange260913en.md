# Explanation of Changes to HomeworkChecker's Licensing Model
Date: September 13, 2026  
Editor: XFTY

**Starting from the [78f9093](https://github.com/XFTY/HomeworkChecker/commit/78f9093ef989ba86458206746606f6a52dcdcb91) commit on September 13, 2026** (excluding that commit), the licensing model of the HomeworkChecker open-source software will change from the original **GNU GPL Version 3** license to the **Apache License 2.0**.

**However, please note: code and binary files (releases) published before the [78f9093](https://github.com/XFTY/HomeworkChecker/commit/78f9093ef989ba86458206746606f6a52dcdcb91) commit (inclusive) still follow the GNU GPLv3 license.**

This means that after the release of this commit, you can use the source code and binary files (releases) of this software more freely, but you need to pay attention to the requirements of the Apache License 2.0.
